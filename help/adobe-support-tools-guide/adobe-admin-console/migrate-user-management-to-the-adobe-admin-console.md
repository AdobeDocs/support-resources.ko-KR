# Admin Console으로 Frame.io 사용자 관리 마이그레이션

적격한 V4 계정을 중앙 집중식 사용자로 전환하려면 Frame.io 계정 팀에 문의하십시오.
관리.

>[!NOTE]
>
>Frame.io의 웹 및 모바일 앱은 영어, 일본어, 독일어, 러시아어,
스페인어, 이탈리아어, 프랑스어 및 포르투갈어(브라질).

계정 팀에 문의하기 전에 조직이 자격 요구 사항을 충족하는지 확인하고 마이그레이션 계획에 참여해야 하는 이해 당사자를 파악하십시오.

- Frame.io V4 엔터프라이즈 계정(2024년 10월 이후에 생성된 계정 또는 V4로 이미 마이그레이션된 계정)
- Enterprise 및 Teams는 Adobe Admin Console 및 Global Admin Console을 통해 Frame.io를 관리할 계획입니다.
- 현재 Frame.io 계정 버전을 확인하기 위한 시스템 관리자 액세스 권한
- Frame.io 계정 팀의 연락처 정보

## 자격 확인 및 마이그레이션 요청

1. Frame.io [enterprise 계정](https://accounts.frame.io/welcome)에 로그인하고 계정이 V4에 있는지 확인하십시오.
1. Frame.io 계정 팀에 문의하여 Adobe Admin Console 사용자 관리로 마이그레이션을 요청하십시오.
1. 마이그레이션 타이밍 및 롤아웃에 대해 Adobe 계정 팀과 협력합니다.
1. 영향을 받는 관리자 및 사용자에게 모든 로그인 또는 액세스 변경 사항을 전달합니다.

팀에서 마이그레이션을 완료하면 Frame.io 사용자를 관리하고 Frame.io 인터페이스 대신 Adobe Admin Console에서 역할을 할당할 수 있습니다. 기존 사용자는 전환 중에 액세스 및 권한을 유지합니다.

계정이 자격 기준을 충족하지 않는 경우 Frame.io 계정 팀에 문의하여 Adobe Admin Console 사용자 관리를 위한 자격을 얻기 위한 옵션을 살펴보십시오.
