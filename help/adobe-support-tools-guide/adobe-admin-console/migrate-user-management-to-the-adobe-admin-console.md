# Adobe Admin Console으로 사용자 관리 마이그레이션

Adobe 계정 팀에 문의하여 Adobe Admin Console을 통해 적격한 솔루션을 중앙 사용자 관리로 전환하는 방법에 대해 알아보십시오.

Adobe 계정 팀에 문의하기 전에 조직이 자격 요구 사항을 충족하는지 확인하고 마이그레이션 계획에 참여할 이해 당사자를 확인하십시오.

마이그레이션 자격 요건은 솔루션에 따라 다릅니다. 마이그레이션 프로세스를 시작하기 전에 조직에서 다음을 수행해야 합니다.

- Adobe Admin Console 기반 사용자 관리로의 마이그레이션을 지원하는 적격 엔터프라이즈 솔루션 또는 배포입니다.
- 해당되는 경우 Adobe Admin Console에 액세스
- 현재 사용자 관리 구성을 검토하려면 관리 액세스 권한이 필요합니다.
- Adobe 계정 팀이나 구현 담당자에 대한 연락처 정보입니다.
- 솔루션별 사전 요구 사항(해당하는 경우)이 완료되었습니다.

## 자격 확인 및 마이그레이션 요청

1. 현재 솔루션 구성을 검토하고 Adobe Admin Console 기반 사용자 관리로의 마이그레이션을 지원하는지 확인하십시오.
2. 솔루션별 자격 요건 및 사전 요구 사항을 검토하십시오.
3. Adobe 계정 팀에 문의하여 Adobe Admin Console 사용자 관리로 마이그레이션을 요청하십시오.
4. Adobe 계정 팀과 협력하여 마이그레이션 시간, 구현 요구 사항 및 조직 준비 상태를 검토하십시오.
5. 영향을 받는 관리자 및 사용자에게 모든 로그인 또는 액세스 변경 사항을 전달합니다.

## 마이그레이션 후

마이그레이션이 완료되면:

- 사용자 관리는 Adobe Admin Console을 통해 관리됩니다.
- 조직의 ID 구성을 기반으로 사용자 로그인 및 액세스 경험을 업데이트할 수 있습니다.
- 솔루션에 대한 별도의 문서가 없는 한, 지속적인 사용자 라이프사이클 관리 활동은 Adobe Admin Console을 통해 수행해야 합니다.

조직이 자격 기준을 충족하지 않는 경우 Adobe 계정 팀에 문의하여 Adobe Admin Console 사용자 관리 자격을 얻기 위한 옵션을 살펴보십시오.
